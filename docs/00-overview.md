# Step 0: 프로젝트 개요 및 조건 정의

> **이 단계의 목표:** 프로젝트의 배경, 목표, 제약 조건을 명확히 정의하여 이후 모든 의사결정의 기준을 세운다.

---

## 0-1. 프로젝트 배경

회사 공식 홈페이지가 아직 없는 상태에서, **바이브코딩(Vibe Coding)** 방식으로 빠르게 구축한다.
바이브코딩이란 AI 코딩 어시스턴트(Claude Code 등)와 자연어 대화를 통해 코드를 생성·수정하는 개발 방식이다.

### 바이브코딩의 핵심 원칙

| 원칙 | 설명 |
|------|------|
| **자연어 우선** | 코드를 직접 타이핑하기보다, 원하는 결과를 자연어로 설명하고 AI가 코드를 생성 |
| **반복적 개선** | 한 번에 완벽한 결과를 기대하지 않고, AI 출력물을 검토 → 피드백 → 재생성 반복 |
| **컨텍스트 관리** | CLAUDE.md 같은 컨텍스트 파일로 프로젝트 규칙을 AI에게 지속적으로 전달 |
| **단위 작업 분리** | 한 번에 하나의 페이지/기능만 요청하여 AI 출력 품질을 유지 |

---

## 0-2. 프로젝트 목표

1. **회사 소개 웹사이트 구축** — 메인, 회사소개, 솔루션, 채용, 문의 5개 섹션
2. **비개발자도 콘텐츠 수정 가능** — 마케팅/HR 담당자가 텍스트·이미지를 직접 편집
3. **무료 운영** — 호스팅 비용 월 $0 (무료 티어 범위 내)
4. **CI/CD 자동화** — PR 검증 + 자동 배포 파이프라인 완성
5. **재현 가능한 문서화** — 이 가이드만으로 처음부터 다시 구축할 수 있어야 함

## 0-3. 프로젝트 조건 및 제약

### 인력 및 예산

| 항목 | 조건 |
|------|------|
| 개발자 | 1명 (Claude Code + 바이브코딩 기반) |
| 디자이너 | 없음 (AI 생성 + Tailwind CSS로 대체) |
| 월 호스팅 예산 | $0 (Vercel Hobby 무료 티어) |
| 도메인 | 별도 구매 또는 기존 보유 도메인 연결 |

### 필요 페이지 상세

| 페이지 | URL 경로 | 주요 콘텐츠 | 비개발자 수정 필요 |
|--------|----------|------------|:-:|
| 메인 (홈) | `/` | 히어로, 핵심 가치, 솔루션 미리보기, CTA | O |
| 회사소개 | `/about` | 회사 비전/미션, 연혁, 팀 소개 | O |
| 솔루션 목록 | `/solutions` | 제품/서비스 카드 그리드 | O |
| 솔루션 상세 | `/solutions/[slug]` | 제품별 상세 설명, 기능 목록, 스크린샷 | O |
| 채용 | `/careers` | 채용 공고 목록, 복지/문화 소개 | O |
| 문의 | `/contact` | 문의 폼, 회사 위치/연락처 | △ (폼 필드는 개발자) |

### 비기능 요구사항

| 항목 | 기준 |
|------|------|
| 성능 | Lighthouse Performance 90+ |
| SEO | Lighthouse SEO 90+, 메타 태그/OG 태그 완비 |
| 접근성 | 시맨틱 HTML, alt 텍스트, 키보드 내비게이션 |
| 반응형 | 모바일(360px) ~ 데스크톱(1440px) 대응 |

## 0-4. 의사결정 우선순위 매트릭스

기술스택 선택부터 구현 방식까지, 모든 의사결정은 아래 우선순위를 따른다.

```
1순위: 바이브코딩(AI 보조) 친화성
  └─ Claude Code로 생성/수정이 쉬운 구조인가?
  └─ AI가 이 기술의 패턴을 잘 알고 있는가?

2순위: 무료/저비용 운영
  └─ 무료 티어로 운영 가능한가?
  └─ 숨겨진 비용(API 호출 제한 등)은 없는가?

3순위: 비개발자 콘텐츠 수정
  └─ 마크다운/GUI로 콘텐츠를 편집할 수 있는가?
  └─ 편집 후 배포까지 자동화되는가?

4순위: 빠른 초기 개발 속도
  └─ 보일러플레이트 최소, 바로 페이지 개발에 진입할 수 있는가?
```
